What you can do

Facilities

GET /facilities

Licenses

GET /licenses

Inspections

Record compliance inspections, findings and inspector attribution.

GET /inspections

Audit logs

Trace logins, permission denials and data changes (Admin only).

GET /audit-logs

Quick start

curl -X POST "$BASE_URL/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"YourPassword"}'

Use the returned access_token as a Bearer token on every protected endpoint. Try it interactively in the Swagger UI.

Security by design

  • JWT access tokens with issuer, audience and expiry validation
  • Explicit token revocation on logout (denylist until expiry)
  • Argon2id password hashing and a password complexity policy
  • Role-based access control and object-level authorization
  • SQL-injection-safe parameterized ORM queries
  • Security headers, CSP, HSTS, CORS and trusted-host controls
  • Login rate limiting and append-only audit logging
